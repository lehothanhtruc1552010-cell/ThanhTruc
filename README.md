# Study Garden

Website học tập gamification **Study Garden – Learn. Grow. Bloom.**

## Chạy dự án
Mở `index.html` trực tiếp trong trình duyệt hoặc triển khai repository này bằng GitHub Pages/Netlify.

Dữ liệu demo được lưu trong `localStorage`. Website có Dashboard, Pomodoro, flashcard, mind map, farm 2D, shop, profile, streak, responsive UI, SEO meta tags và PWA manifest.

## Cấu trúc
- `index.html`: giao diện và SEO cơ bản
- `style.css`: giao diện pastel responsive
- `script.js`: logic tương tác và localStorage
- `manifest.json`: PWA metadata
- `icon.svg`: favicon/app icon
